# Canvas · Colab 创意工作台

本地创意画布，沿用本项目的 Colab CLI、SSH 隧道、ComfyUI 部署和任务恢复能力。项目、提示词、素材和输出保存在本机；GPU 生成在 Colab 执行。

独立仓库：`BelugaStd/colab-canvas-workbench`。基于 0bCyan 的 `colab-workbench` 二次开发，保留原 MIT 版权声明。

## 首次从源码安装

准备 Python 3.12、uv、Node.js 24、ffmpeg/ffprobe 和 OpenSSH，然后执行：

```powershell
git clone https://github.com/BelugaStd/colab-canvas-workbench.git
cd colab-canvas-workbench
uv sync --frozen
npm --prefix frontend ci
npm --prefix frontend run build
uv run python scripts/start_windows.py
```

上述步骤启动本地界面。Colab 登录和 GPU 连接还需要在本机安装、配置独立的 Colab CLI 账号启动器；Windows 当前使用本地配置的 CLI 0.8.0 兼容环境。仓库不包含该运行环境、任何账号授权、SSH 私钥或已有项目数据，新克隆不会继承原电脑的登录。macOS/Linux 启动脚本为 `scripts/start.sh`，同样需要先配置 Colab CLI。

## 本机启动

Windows 双击项目根目录或 outputs 中的「启动工作台.cmd」，打开 http://127.0.0.1:8765 。启动器会复用兼容的后台；若检测到旧后台，会提示先正常退出，不打开旧界面。

本机已经配置 Python 3.12、独立 CLI 0.8.0 环境、OpenSSH、多账号启动器与 SSH 密钥。账号 1 的现有登录信息继续使用。其他账号运行 outputs 中相应的「登录Colab账号N.cmd」，完成 Google 授权后刷新算力面板。凭证不复制到 GPU。

正常退出在启动窗口按 Ctrl+C。仅关闭网页不会停止后台。默认空闲 15 分钟释放 GPU，也可在高级面板修改。

## 从登录到生成

1. 打开或新建项目，点击左下角算力小窗。
2. 选择已登录账号，点击「连接服务器」。程序自动申请或复用本工作台的 GPU，安装固定版本 ComfyUI，下载全部创作模型，建立 SSH 与监控连接。首次下载需要等待；界面显示就绪后可直接生成。
3. 双击或右键画布添加图片、视频、文本、超分节点，也可拖入文件。I / V / T / U 分别创建图片、视频、文本或上传素材。
4. 把上游右端连接点拖到下游左端。选中下游，输入提示词，用 @ 选择已经连接的素材。每条连线有稳定的「@图N / @文本N」编号，重命名节点不会改变编号。所有连入图片都会参与生成；@ 用来描述各图用途，不是开启参考的开关。连入文本自动加入提示词。
5. 选中节点展开提示词和设置。点击节点箭头生成，或使用右上角「生成所选 / 全部」。结果取回本地后出现在对应节点和素材库。
6. 双击媒体或点击放大按钮查看详情，修改提示词和参数后可在原节点重新生成。每次结果保存为一个版本；单击版本缩略图查看，双击设为实际输出，下游参考使用这个版本。切换输出不会覆盖正在编辑的提示词，可用「使用此版本参数」恢复历史设置。

## 模型和简化设置

| 节点 | 模型 | 提供的设置 |
| --- | --- | --- |
| 视频 | MiniMax H3 INT8 ConvRot，普通 20 步；主体参考使用独立 REF2VA 权重 | 5–15 秒、24/30 fps、声音、六种画幅或跟随主图、512p/768p、五种参考模式 |
| 图片 | MiniMax Image、普通 MOSS Image SFT / Edit LoRA、Qwen Image Edit 2511 INT8 ConvRot | 六种画幅或跟随主图、模型对应分辨率、标准/精细；Qwen 专用于 1–3 图编辑/参考创作 |
| 图片超分 | 官方 Real-ESRGAN x4plus | 2× / 4× |
| 视频超分 | SeedVR2 7B 自然 / 7B Sharp 细节 / 3B 均衡（均为 FP16） | 2× / 4×，保持比例，最高 4K 像素预算 |

H3 生成尺寸限制在官方推荐的 1344×768 像素预算内，按官方 32 像素网格对齐。模型原生生成 24 fps，30 fps 为导出重采样。导出保留音频、精确时长；循环模式用首尾同图条件及短过渡降低接缝，不能保证所有提示词都产生完全无感的动作循环。

MiniMax Image 的 1K/2K 按约 1M/4M 像素面积计算，默认 2K；1K 适合快速预览，画质较低。MOSS 可选 1/1.5/2MP，旧项目的 1K/2K 分别映射 1/2MP。具体宽高随画幅变化；默认跟随主图，无参考时图片为 1:1、视频为 16:9。精细质量在生成后使用 Real-ESRGAN 增强，再回到所选尺寸。

Qwen Edit 使用官方 2511 INT8 ConvRot、Qwen 2.5 VL 文本编码器及 Qwen Image VAE，三文件共约 30.1GB。连接 1–3 张图片，第一张为主图，按 @图编号描述其它图片的用途；不提供无图片的文生图。输出采用推荐 1MP、40 步、CFG 4；跟随主图保留画幅，自选画幅会居中裁切主图。参数和确切输入仍保存为节点版本，可编辑后重新生成。该预设沿用本项目的 Blackwell / CUDA 13 要求。

MOSS 文生图采用普通 SFT，编辑使用作者的实验 Edit LoRA、SLG single layer 22 与匹配参考尺寸。真机测试仍观察到插画变照片、背景变化和多图主体混淆；严格保留人物、风格、构图或多图合成请优先选择默认的 MiniMax Image。明确写出要保留的视觉风格会有帮助，但不保证完全保真。没有部署另行定制的 NSFW 模型。

图片/视频生成当前接受图片和文本参考。视频、音频可上传、预览和管理；视频可以接超分，不能作为当前生成模型的参考。MiniMax Image 最多 10 张图片参考，MOSS 最多 4 张，Qwen Edit 为 1–3 张。

| 视频模式 | 连接图片数 | 用途 |
| --- | --- | --- |
| 文生视频 | 0 | 仅用文字生成 |
| 首帧 | 1 | 固定开始画面，描述后续动作 |
| 首尾帧 | 2 | 固定开始和结束画面；可交换首尾用途 |
| 首尾循环 | 1 | 同图作为开始和结束；描述可回到起点的动作 |
| 参考图 | 1–9 | 参考主体和外观，使用 REF2VA，不固定首尾 |

图片「编辑主图」保留未要求修改的内容；「参考创作」根据参考重新构图。多图编辑可选择主图，其它图在提示词中说明用途，例如「把 @图2 的机器人放到 @图1 杯子右边」。首尾视频会居中裁切输入至输出画幅，选择跟随主图可避免主图画幅被改变。模式与图片数量不匹配、引用已断开、旧名称有歧义时，会明确阻止生成，不会悄悄改为文生图或文生视频。

只生成下游时，有结果的上游使用当前所选输出版本；缺少结果的上游会按依赖生成。批量同时选中上游和下游时，上游重新生成一次，下游使用这次新结果。详情保存生成时的提示词、种子、尺寸、模式及确切参考素材；恢复历史参数保留当前连线。

视频可连接超分节点。选中节点，打开设置选择上述三个权重之一，默认使用 7B 自然版；它们属于同一个 SeedVR2 架构，分别侧重自然还原、锐利细节和速度，并非三种不同架构，也不宣称对所有素材都排名前三。连接图片时自动使用原有 Real-ESRGAN。可将未生成的 H3 视频连接超分，系统按依赖顺序完成生成、超分与本地保存；同账号串行、不同账号并行的调度不变。

SeedVR2 使用[官方 ComfyUI 集成及独立 CLI](https://github.com/numz/ComfyUI-SeedVR2_VideoUpscaler)固定提交 `4490bd1f482e026674543386bb2a4d176da245b9`，以及 [numz/SeedVR2_comfyUI](https://huggingface.co/numz/SeedVR2_comfyUI) 固定版本 `09ced71023636e9bc8cdf9cdecfb2625d1e691e8`。一键连接准备全部三个权重及共享 VAE；任务触发连接时只下载所需模型。使用独立 Python 环境、SDPA、VAE 分块和带重叠的时序分段，不要求编译第三方稀疏注意力扩展。

视频超分支持最长 120 秒、1–120 fps 的素材，保留帧数、帧率和原有音轨，音频导出为 AAC。输出最长边不超过 3840，像素总量不超过 3840×2160；超过预算自动按比例限制，界面中的 4× 为请求倍数。原片已达到该上限时会明确提示。超分不会插帧；已有循环视频的连续性取决于源片和模型处理。首轮下载和 FP16 推理耗时较长，7B/Sharp 占用高于 3B。每次重新超分会保存为该节点的新版本，可双击版本切换实际输出。

## 画布与项目

- 项目、文件夹、网格/列表、搜索、多选、重命名、复制、移动、回收与恢复。
- 多张画布，独立节点位置、连接关系和缩放；编辑自动保存。并发窗口发生版本冲突会明确报错，防止覆盖。
- 重复点击当前模型保留已选分辨率；中文输入候选期间按 Esc 不关闭弹窗，结束候选后可用 Esc 退出。
- 拖动、平移、缩放、小地图、节点搜索、预览和本地素材库。
- 选中节点仍可从标题、媒体预览和空白区域拖动；输入框、播放控件与连线端口各自响应操作，不再提供固定节点。
- 浮层、详情、设置、侧栏与节点编辑区带进入、退出或展开过渡，使用半透明毛玻璃；尊重系统减少动态效果设置。
- Shift 多选；Ctrl+A 全选；Ctrl+D 创建副本；Ctrl+C / Ctrl+V 复制粘贴；Delete 删除；Ctrl+Z / Ctrl+Shift+Z 撤销重做。
- Ctrl+G 分组，Ctrl+Shift+G 取消选中分组。分组支持移动和调整边框，不支持嵌套分组。

界面依据观察到的 Tapnow 画布与项目页实现。本项目不含其云端团队、分享、付费服务或 Agent；也不宣称与其所有未观察功能逐像素相同。

## 调度、监控与恢复

每个账号独立 GPU 与队列。同一 GPU 串行，不同账号的任务可并行；账号选择决定新任务的目标。一次批量最多 20 个目标节点，依赖合成同一张执行图，共享上游只生成一次。正在生成的节点及其共享上游会阻止重复提交。

左下角小窗显示账号余额、账号总消耗率、GPU/CPU 占用、功率、显存和内存。资源约每 2.5 秒刷新，官方额度每 45 秒刷新；余额中间值按速率估算。账号消耗包含账号内其他会话。断开后清除资源读数。

点击小窗进入高级面板，查看资源、任务、部署日志和远程 Linux 命令行。命令行仅能访问本工作台已就绪且归属匹配的 GPU。它是真实服务器命令，不是本机终端。

任务提交前保存唯一 ID。断线后通过原 ID 查询队列和结果，不自动重复生成。后台重启后点击连接复用已记录会话。释放只操作当前工作台创建的会话，不处理其他来源的 GPU。

## 数据与依赖

正式数据位于 `.data/`，测试数据独立存放。不要删除该目录中的凭证、密钥、SQLite 数据库、assets 或 outputs。Colab 临时盘在释放后清空，下次新建 GPU 会重新下载模型。自动关机需要本地后台和 Colab 连接仍能工作。

部署清单在 `backend/deploy_remote.py`，模型和 ComfyUI 固定到具体修订；Real-ESRGAN 使用官方发布文件与 SHA256 校验。外部登录、下载限速和 Colab 容量变化仍可能影响连接，失败信息会保留在高级面板。

部署默认同时下载 4 个文件，并与依赖安装重叠；共享权重只下载一次。云端 `WB_DOWNLOAD_WORKERS` 可设 1–8。Xet 初始/最大下载流默认限制为 4/16，避免文件并发叠加高性能模式触发 CDN 限速；429、临时服务或网络错误按文件退避重试并保留下载缓存，权限和文件不存在的错误直接报告。固定版本缓存通过清单和文件尺寸检查后直接复用，省去重复网络查询；已完成的依赖安装、Git 提交和包缓存也会复用。云端仅安装 API 推理依赖，本地画布使用自己的前端。

断网后，已提交任务会持续退避重连原 GPU 并查询原 prompt，不再因一次重连失败或几次网络抖动永久停在恢复中。新旧 SSH 429 提示均可恢复；原会话已释放时明确失败，不自动申请替代 GPU 或重复提交。已有 GPU 的旧助手不识别 Qwen 时，仅更新模型下载助手并复用运行中的 ComfyUI。
