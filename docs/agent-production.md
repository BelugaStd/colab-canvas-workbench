# 专业剧集制作与验收

超过 90 秒、剧集或精确连续性任务采用制作台账。Agent 在原有侧栏自主完成开发、资产、配音、分镜、生成、审片、合片与混音；画布和实际素材仍是可编辑的真实产物。

## 制作流程

1. 保存原创故事的矛盾、人物诉求、行动升级、代价、本集兑现与续集问题。
2. 定义人物、地点、关键道具及角色固定声线。分别生成清晰母版，独立实图审查后发布不可变版本。
3. 批量生成角色对白，按实际采样数测量时长，再安排镜头和声音时间线。
4. 分场明确地理、轴线、光线；逐镜记录用途、动作、景别、焦段、运镜动机、视线和出入状态。
5. 静帧连接锁定原图。状态变化使用经审查的精确首尾图；代表性风险镜头通过后扩大生成。
6. 独立检查每个视频版本。Agent 自主保留旧版并有限返工，持续关键缺陷则停止扩散。
7. 按批准镜头的精确版本、裁入点和时长合片；对白混音完成后审查当前成片。

这套流程借鉴场记、角色设计、分镜与剪辑工作，不把摄影术语数量当成专业程度。镜头运动必须服务信息揭示、人物关系或情绪变化；固定机位也是有效选择。

## 资产与版本边界

`canvas.production` 保存 brief、entities、scenes、shots、locks 和当前成片。发布版本保存原图 SHA256、人物或场景设定快照以及 `locked-*` 参考节点。新的候选和换装不会替换旧发布版本。

每镜显式绑定出镜人物、场景和关键道具的版本。工具检查实际依赖连线；视频首尾引用必须就是镜头表中已经批准的静帧，不能仅在提示词中声称引用了某人物。已发布快照允许移动，不能改变或删除其输出。

镜头的 `source_duration` 是 5–15 秒 H3 原片，`start` 和 `duration` 是实际采用的裁切区间。全片时长来自有序镜头之和；不能用循环、静帧或补黑冒充独立动态镜头。

## 独立审查与交付

`review_media` 使用独立模型上下文检查实际图片或视频抽帧，对照原始锁定参考和当前镜头契约。每次检查记录身份、连续性、动作、摄影和伪影五项证据，绑定媒体 SHA256、契约指纹与审查版本。

单镜取多个时间点；成片联系表覆盖每个计划镜头。素材或契约变化会使旧批准失效。模型接口不可用、响应不完整或证据缺失时停止后续生成，不以新候选反复消耗算力来解决审查服务故障。

合片必须一一匹配当前完整镜头表及每镜批准。成片对白须覆盖已保存台词，并匹配角色固定声线；只有环境音不能通过对白交付检查。未通过 `production_status.complete` 时，Agent 不可把任务声明为完整交付。

抽帧检查不能证明整个运动过程、声音表演或口型同步。编码、采样数、响度与 ASR 检查也不能替代完整播放和听感评价；报告应明确尚未验证的维度。

## 配音与显存调度

Qwen3-TTS 1.7B CustomVoice 在当前拥有的 Colab GPU 上批量合成，固定角色 voice，每批只加载一次。使用固定依赖版本、独立环境和逐句磁盘缓存；恢复使用原持久任务 ID，不重新申请 GPU。

TTS 与图像/视频推理在同账号串行。导入 CUDA 前先查询显存，空闲少于 12 GiB 时仅在 Comfy 队列为空的条件下释放驻留模型。保留 Comfy 进程和磁盘权重；队列忙或状态未知时明确阻塞。不能用会自行建立 CUDA context 的预检去检查几乎耗尽的显存。

取消本地等待不代表远端语音已经结束。未确认任务阻止新的 GPU 工作和普通关机；状态读取仅查询原任务。已生成句子可重新下载，结果不明时不能盲目重复付费。

配音是后期 dubbing，`lip_sync=false`。可用画外声、反应、侧背影和细节镜头安排声画关系，不将随机嘴动宣称为同步对白。

`mix_sound` 使用本地语音素材及明确时间码，校验原文、角色声线、时长、越界和重叠，按 48 kHz 样本定位并处理 duck/fade、两遍响度归一。视频码流保持不变，验证帧数、时长和完整解码；声音时间线保留在素材元数据中。

## 自主能力评测

外部 QA 只读观察。效果不佳时，修改通用 Agent 规则或工具后在新项目重跑任务级 brief；不向运行中的导演发送逐镜修复、对白改写或选片指令。保存尝试记录、冻结源码指纹和原始失败证据，区分基础设施修复与创作干预。

同一次授权的 CU 总账跨项目共享，记录已观察到的余额下降，充值或退款不会重置已用额度。实际消耗与按最后费率、采样账龄计算的估算分别显示；非有限、超过 60 秒未更新或读取失败的额度禁止新增推理。

对已授权且已拥有的会话，后台每 30 秒核对额度，单次刷新最多等待 10 秒。实际或估算额度到 5 CU 预留底线，或额度连续失联 120 秒时，强制停止该自有 GPU；停机失败显示未确认并继续重试。没有预算台账的正常会话保持原有回收规则。本地后台必须运行，Colab 停机接口也必须可达，才能确认释放，不能承诺网络完全中断时仍绝不超额。

- [FFmpeg filters](https://ffmpeg.org/ffmpeg-filters.html)：混音、响度与技术异常检测；检测结果不代替审美判断。
